OCR PDF

Recognize text in scanned pages and add an invisible text layer, making the original PDF searchable and selectable.

✓ OCR runs in your browser. Your PDF is not uploaded. The language model downloads on first use.

Best for scanned or image-only PDFs. English recognition is available in this first version. Existing PDF content is retained; OCR adds a searchable text layer.

Repair PDF

Try to rebuild a damaged or malformed PDF and save a fresh copy. Your original file is never changed.

✓Rebuilds the PDF document structure and writes a fresh file. No upload required.

Can help with some structural and cross-reference issues. Severely corrupted, encrypted, or incomplete files may not be recoverable. This tool does not reconstruct missing page content.
