# PDF Tool

Browser-only PDF tool: merge, organize pages, insert pictures/text, compress.
Files never leave the user's device. Hosted as a Render Static Site.

## Libraries (self-hosted in vendor/)
- pdf-lib 1.17.1
- PDF.js (pdfjs-dist) 4.10.38
